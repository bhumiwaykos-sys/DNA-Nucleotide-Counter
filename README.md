
# DNA Nucleotide Counter

## About
This is a beginner-friendly bioinformatics project
developed using Python to count nucleotides in a
DNA sequence.

## Objective

To calculate the number of Adenine (A), Thymine (T),
Guanine (G), and Cytosine (C) nucleotides.

## Technologies Used
- Python
- Basic string manipulation

## Features
- Accepts a DNA sequence from the user
- Converts lowercase input to uppercase
- Counts A, T, G, and C separately

## Example
Input: ATGCGATACG

Output:
A count: 3
T count: 2
G count: 3
C count: 2

## Project Type
Beginner Bioinformatics Project
